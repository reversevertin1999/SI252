第八题解答检验与解释

结论：解答是对的。 用 200 万次蒙特卡洛模拟验证：模拟的期望返回值 ≈ 1.35906，与 $e/2 \approx 1.35914$ 吻合。顺带一提，模拟的平均抽取次数 ≈ 2.7185，正好等于 $e$，这也是本题的经典伴生结论。

整体思路

程序每次抽 $U\sim\mathrm{Unif}(0,1)$ 累加，直到和超过 1。由于每次抽样独立同分布，未来只取决于当前的和 $x$，所以可以定义「价值函数」：

$$g(x) = \text{当前和为 } x \text{ 时，最终返回值的期望}$$

答案就是 $g(0)$。整个解法是：一步展开 → 积分方程 → 求导变成微分方程 → 解出通解 → 用边界条件定常数。

逐步解释

① 积分方程（一步展开）

看下一次抽样 $U$：

  • 若 $U \le 1-x$：新和为 $x+U$，还没超过 1，继续，期望变成 $g(x+U)$；
  • 若 $U > 1-x$：新和 $x+U > 1$，立刻返回 $x+U$。

由于 $U$ 的密度是 1，直接对 $u$ 积分（本质是全期望公式）：

$$g(x)=\int_0^{1-x}g(x+u)\,\mathrm{d}u+\int_{1-x}^1(x+u)\,\mathrm{d}u$$

第二个积分可以直接算出来：

$$\int_{1-x}^1(x+u)\,\mathrm{d}u = x + \frac{x^2}{2}$$

第一个积分换元 $v=x+u$ 后变成 $\int_x^1 g(v)\,\mathrm{d}v$，于是

$$g(x)=\int_x^1 g(v)\,\mathrm{d}v+x+\frac{x^2}{2}$$

② 求导降阶成 ODE

两边对 $x$ 求导，由微积分基本定理 $\dfrac{\mathrm{d}}{\mathrm{d}x}\displaystyle\int_x^1 g(v)\,\mathrm{d}v = -g(x)$，得

$$g'(x) = -g(x) + 1 + x \quad\Longleftrightarrow\quad g'(x)+g(x)=1+x$$

积分方程里「$g$ 藏在积分号下」的困难，求一次导就消掉了。

③ 解一阶线性 ODE

乘积分因子 $e^x$：

$$(e^x g(x))' = e^x(1+x) = (xe^x)' \;\Rightarrow\; g(x) = x + Ce^{-x}$$

④ 边界条件 $g(1)=\tfrac32$ —— 全篇最巧妙的一步

通解里有一个未知常数，需要边界信息。关键观察：循环条件是 $sum \le 1$（含等号），所以当和恰好等于 1 时程序还不会停，还要再抽一次；而任何 $U>0$ 都使和严格超过 1，故

$$g(1) = 1 + \mathrm{E}[U] = 1 + \frac12 = \frac32$$

代回通解：$1 + Ce^{-1} = \dfrac32 \Rightarrow C = \dfrac{e}{2}$。

⑤ 收尾

程序从 $x=0$ 出发，所以

$$\mathrm{E}[\text{返回值}] = g(0) = 0 + \frac{e}{2} \approx 1.359$$

直觉与补充

  • 为什么答案大于 1 且小于 2：最终和必然刚超过 1，但超出的部分（overshoot）平均约 0.359，所以期望是 $1 + 0.359$；又因为停止前的和 $\le 1$、最后加的一次 $<1$，返回值恒在 $(1,2)$ 内。
  • 终止性：解答开头的论证（前 $m$ 次中至多一次大于 $\tfrac12$ 的概率是 $(m+1)2^{-m}\to 0$）说明程序几乎必然在有限步内停止，这保证了 $g$ 良定义且有限，也使后面求导合法。
  • 自洽性检查：把 $x=1$ 代回原积分方程也得 $g(1)=0+\tfrac32$，与边界条件一致，说明解没有矛盾。
  • 伴生经典结论：设 $N$ 为停止时抽取的次数，则 $\mathrm{P}(N>n)=\mathrm{P}(S_n\le 1)=\tfrac1{n!}$，从而 $\mathrm{E}[N]=e$；模拟值 2.7185 与之吻合。

模拟验证（Python，200 万次）：E[返回值] = 1.359062 vs e/2 = 1.359141；E[抽取次数] = 2.718467 vs e = 2.718282。
